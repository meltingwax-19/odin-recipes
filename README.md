 # odin-recipes
This project is a recipe website that consist of a main index page which has links to various recipe pages.

WHAT I LEARNED

1.  How to improve my use of the command line to copy, move &  rename files and also change directories.  Thus improving my file system navigation skills using the CLI.

2.  Researched on Google on how best to use 'Attributions' to give credit to other people for the use of their creations, (i.e photos, videos e.c.t) and why it is important to do so.

3.  The importance of doing regular atomic commits of my work and how to use commit related git commands like 'git show', 'git diff', 'git log -p', 'git log --oneline' & 'git shortlog'.  All these provide several specific information on commits.
